# Playwright Browser Automation

Esta habilidad permite navegar e interactuar con páginas web tanto locales (`localhost`) como remotas.

## Procedimiento de navegación
1. **Verificar servidor local**: Si se inspecciona la aplicación del proyecto, asegurarse de que el servidor dev esté corriendo (`npm run dev`).
2. **Navegación**: Abrir la URL objetivo utilizando las herramientas del navegador o MCP de Playwright.
3. **Inspección**: Obtener capturas de pantalla o el snapshot de accesibilidad del DOM para evaluar el diseño, textos y elementos visuales.
4. **Interacción**: Realizar clics, rellenar formularios o ejecutar flujos de prueba paso a paso.
